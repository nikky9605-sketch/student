# Student Performance Analysis

An exploratory data analysis and predictive segmentation project examining student academic performance, risk factors, and institutional intervention strategies.

## Project Overview
* **Objective:** Analyze student demographics, test preparation, and scores to identify at-risk patterns.
* **Key Findings:** Highlighted the impact of test preparation courses on reducing failure rates and improving overall student outcomes.
* **Deliverables:** Complete data cleaning, exploratory visualizations, and a formal Principal's Report embedded in the Jupyter Notebook.

## Built With
* Python (pandas, matplotlib, seaborn)
* Google Colab
* Jupyter Notebook (`.ipynb`)
